## 0. Срочные баги UX

- ✅ **Комбобокс города предлагает стереть уже выбранный город / список «сам» вываливается.**
  Причина: `visibleCityOptions` фильтровал по подстроке и **не исключал точное совпадение**,
  поэтому единственной подсказкой оказывался уже введённый город.
  Фикс: исключать точное совпадение из подсказок (`normalized !== query`) в
  `src/components/union-profile-form.tsx`. После выбора города список становится пустым и не всплывает.
- ✅ Открывать список города по фокусу/клику предсказуемо, закрывать по `Escape`
  и при уходе фокуса (`onFocus` открывает список, `onKeyDown` Escape закрывает,
  blur-таймер закрывает при клике вне поля) — `src/components/union-profile-form.tsx`.
