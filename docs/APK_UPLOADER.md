# APK Uploader - Админ-панель

## 📱 Обзор

Сервис для загрузки, управления и распространения APK файлов тестировщикам через админ-панель VedaMatch.

---

## 🚀 Возможности

- ✅ **Загрузка APK** через drag-and-drop или выбор файла
- ✅ **Автоматическое версионирование** (извлекается из имени файла)
- ✅ **Прямые ссылки** на скачивание из S3
- ✅ **Копирование ссылки** в один клик
- ✅ **Удаление файлов** из S3
- ✅ **Список всех загрузок** с метаданными
- ✅ **Валидация** (только .apk, макс. 200MB)
- ✅ **Индикатор прогресса** загрузки

---

## 📍 Доступ

**URL:** `https://admin.vedamatch.ru/admin/apk-uploader`

Требуется авторизация как администратор.

---

## 🔧 API Endpoints

### Загрузка APK
```
POST /api/admin/apk/upload
Content-Type: multipart/form-data

Params:
- file: APK файл (макс. 200MB)

Response:
{
  "success": true,
  "url": "https://s3.firstvds.ru/.../ragagent-release-v1.1.29-20260316-120000.apk",
  "filename": "ragagent-release-v1.1.29-20260316-120000.apk",
  "size": 88729592,
  "version": "1.1.29"
}
```

### Список APK файлов
```
GET /api/admin/apk/list

Response:
{
  "success": true,
  "files": [
    {
      "filename": "ragagent-release-v1.1.29-20260316-120000.apk",
      "url": "https://s3.firstvds.ru/.../ragagent-release-v1.1.29-20260316-120000.apk",
      "size": 88729592,
      "uploadedAt": "2026-03-16T12:00:00Z",
      "version": "1.1.29"
    }
  ]
}
```

### Удаление APK
```
DELETE /api/admin/apk/:filename

Response:
{
  "success": true,
  "message": "File deleted successfully"
}
```

## 💡 Как использовать

### 1. Загрузка нового APK

1. Откройте `/admin/apk-uploader`
2. Перетащите `.apk` файл в зону загрузки или нажмите "Выбрать файл"
3. Дождитесь завершения загрузки (индикатор прогресса)
4. Файл автоматически сохранится в S3: `downloads/android/ragagent-release-v{version}-{timestamp}.apk`

### 2. Копирование ссылки

1. Найдите нужный файл в списке "Загруженные APK файлы"
2. Нажмите кнопку 📋 (Копировать)
3. Ссылка скопирована в буфер обмена

### 3. Скачивание APK

1. Нажмите кнопку ⬇️ (Скачать) рядом с файлом
2. Файл загрузится на ваше устройство

### 4. Удаление APK

1. Нажмите кнопку 🗑️ (Удалить) рядом с файлом
2. Подтвердите удаление
3. Файл будет удален из S3

## 📝 Формат именования

Автоматически генерируется при загрузке:
```
ragagent-release-v{version}-{YYYYMMDD-HHMMSS}.apk
```

Примеры:
- `ragagent-release-v1.1.29-20260316-120000.apk`
- `ragagent-release-v1.0.0-20260315-093000.apk`

Версия извлекается из исходного имени файла (если есть).

## 🛠 Troubleshooting

### Ошибка "Failed to upload to S3"
- Проверьте подключение к интернету
- Убедитесь, что S3 credentials настроены в `.env`
- Проверьте логи сервера

### Ошибка "File size exceeds 200MB limit"
- Сожмите APK или используйте App Bundle
- Разбейте на части (не рекомендуется)

### Файл не отображается в списке
- Обновите страницу
- Проверьте, что файл успешно загружен (статус 200)
- Проверьте S3 bucket через консоль
