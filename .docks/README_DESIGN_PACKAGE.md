## 🎯 Рекомендуемая последовательность работы

### Для дизайнера (Stitch):

1. **Читаем**: `DESIGN_BRIEF_ADS.md` (10 мин)
2. **Изучаем**: `DESIGN_SPEC_ADS.md` → раздел "Текущий дизайн" (15 мин)
3. **Создаем**: 
   - Главный экран (список объявлений)
   - Форма создания объявления
   - Детальный просмотр
   - Модальное окно фильтров
4. **Экспортируем**:
   - PNG @3x (screens)
   - SVG (icons)
   - JSON/CSS (styles)

### Для разработчика:

1. **Backend**: `DATA_STRUCTURE_ADS.md`
   - Создаем таблицы в БД
   - Реализуем API endpoints
   - Добавляем валидацию

2. **Frontend**: 
   - `DESIGN_SPEC_ADS.md` → компоненты
   - `TRANSLATIONS_ADS.md` → добавляем переводы
   - `DATA_STRUCTURE_ADS.md` → TypeScript types

3. **Тестируем** с mock data

## 💡 Важные моменты для дизайнера

### ✨ Ключевые фишки дизайна:

1. **Glassmorphism** везде где возможно
   - Bottom navigation (уже есть в приложении)
   - Tab switcher
   - Category pills
   - Модальные окна

2. **Warm Colors** (теплая палитра)
   - Шафрановый, золотой, кремовый
   - Ассоциация с ведической культурой
   - Премиальный вид

3. **Емодзи для категорий**
   - Вместо иконок используем emoji
   - Быстро, понятно, универсально

4. **Мягкие тени**
   - Все элементы "парят" над фоном
   - Теплые оттенки для теней (#D67D3E)

5. **Округлые формы**
   - Border radius везде (8-32px)
   - Никаких острых углов

### 🎨 Референсы:

- **Цветовая гамма**: Pinterest "warm cream aesthetic"
- **Glassmorphism**: iOS 14+ design, macOS Big Sur
- **Cards**: Airbnb, Tinder (swipeable)
- **Bottom Nav**: Modern iOS apps (floating style)
