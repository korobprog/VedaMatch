# ✅ Ежедневный статусный отчёт Veda Match — Настроено!

## 🎉 Готово!

Автоматическая генерация статусных отчётов для Telegram **настроена и работает**.

---

## ⏰ Расписание

**Время запуска:** Каждый день в **9:00 утра** по местному времени (Москва, UTC+3)

**Cron:** `0 9 * * *`

---

## 📁 Файлы

| Файл | Описание |
|------|----------|
| `.agent/scripts/daily-status-simple.sh` | Скрипт генерации отчёта |
| `logs/status-reporter/report-YYYY-MM-DD.md` | Отчёт за день |
| `logs/status-reporter/status-reporter-YYYY-MM-DD.log` | Лог запуска |
| `logs/status-reporter/cron.log` | Лог crontab |

---

## 🧪 Тестовый запуск

### Запустить вручную:

```bash
cd /Users/mamu/Documents/vedicai
./.agent/scripts/daily-status-simple.sh
```

### Посмотреть отчёт:

```bash
# Отчёт за сегодня
cat logs/status-reporter/report-$(date +%Y-%m-%d).md

# Все отчёты
ls -lh logs/status-reporter/
```

## 🔍 Мониторинг

### Проверить последний запуск:

```bash
# Когда последний раз запускался
grep "🚀 Генерация" logs/status-reporter/cron.log | tail -1

# Успешно ли выполнился
grep "✅ Отчёт сгенерирован" logs/status-reporter/cron.log | tail -1
```

### Просмотреть отчёты:

```bash
# Отчёт за сегодня
cat logs/status-reporter/report-$(date +%Y-%m-%d).md

# Отчёт за вчера
cat logs/status-reporter/report-$(date -d yesterday +%Y-%m-%d).md
```

```bash
grep "Коммитов:" logs/status-reporter/*.log | awk '{sum += $2} END {print sum}'
```

## ⚙️ Crontab

### Проверить задание:

```bash
crontab -l | grep status
```

**Ожидаемый вывод:**
```
0 9 * * * /Users/mamu/Documents/vedicai/.agent/scripts/daily-status-simple.sh
```

### Отключить:

```bash

# 0 9 * * * /Users/mamu/Documents/vedicai/.agent/scripts/daily-status-simple.sh
```

```bash

# Раскомментировать строку
```
